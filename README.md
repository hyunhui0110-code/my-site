# 🛒 우리 집 장보기 체크리스트

살 것을 종류별로 정리하고, 산 것은 체크해 두는 간단한 웹 페이지예요.
파일 하나(`장보기.html`)로 되어 있어서 설치 없이 바로 쓸 수 있어요.

## 여는 방법

1. `장보기.html` 파일을 내려받아요.
2. 파일을 더블클릭하면 브라우저에서 열려요.

인터넷 연결이나 서버 없이 내 컴퓨터에서만 동작해요.

## 기능

- **종류별 카드**: 채소·과일 / 고기·생선 / 유제품·달걀 / 가공식품·양념 / 생활용품
- **체크**: 항목을 누르면 체크돼요. 체크한 항목은 줄이 그어지고 카드 맨 아래로 내려가요.
- **추가**: 이름, 수량·메모, 종류를 골라 새 항목을 넣어요. (Enter 키로도 추가)
- **수량·메모**: 항목 옆 메모를 눌러서 고칠 수 있어요.
- **삭제**: 항목 오른쪽 ✕ 버튼으로 지워요.
- **자동 저장**: 바꿀 때마다 브라우저에 저장돼서, 새로고침하거나 창을 닫았다 열어도 그대로 남아요.

## 알아 두면 좋은 점

- 목록은 **파일을 연 그 브라우저 안(localStorage)에만** 저장돼요.
  다른 브라우저나 다른 컴퓨터에서 열면 기본 목록부터 시작해요.
- 브라우저의 사이트 데이터를 지우면 저장된 목록도 지워질 수 있어요.
